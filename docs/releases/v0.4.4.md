# TaipanStack v0.4.4 Release Notes

**TaipanStack v0.4.4** is a critical security hardening and maintenance release. This version addresses zero-day vulnerabilities in dependency management pipelines (including a critical `pip` vulnerability), hardens security guards against null-byte bypasses, and achieves a new milestone of **1,237 passing tests** with verified 100% code coverage.

See documentation at: [TaipanStack Dev Portal](../index.md).

---

## What's New & Fixed in v0.4.4

### 🛡️ Core Security & Sentinel Guards
* **[High] File Extension Hardening (PR #619):** Patched a critical bypass in `guard_file_extension` that allowed null bytes (`\x00`) and trailing periods/whitespace to mask malicious extensions on certain filesystems.
* **[Hardening] Retry Config Resilience (PR #618):** Enforced `math.isfinite` validation in the `RetryConfig` layer to prevent logic corruption or infinite loops caused by `NaN` or `Inf` configuration values.
* **[Audit] Dependency Scanning & CVE Management:** 
    *   Addressed **CVE-2026-3219** (pip) via an explicit, documented ignore-vuln strategy pending upstream patch.
    *   Addressed **PYSEC-2022-42969** (py) legacy vulnerability in transitive dependencies.
    *   Upgraded **pytest to 9.0.3** to remediate **CVE-2025-71176**.

### ⚡ Performance & CI/CD Optimization
* **[CI/CD] Pipeline Streamlining (PR #614):** Optimized GitHub Actions by removing redundant container distribution tests and cleaning up IA-generated residual scripts, resulting in faster and more secure pipelines.
* **[SAST] Standardized Naming:** Enforced strict naming conventions across all CI jobs and steps to ensure auditability and maintainability.

### 🏗️ Refactoring & Clean Code
* **[Typing] Strict Model Dumps (PR #615):** Eliminated remaining `Any` usage in security models by enforcing explicit return types on all serialization methods.
* **[Consistency] Bootstrapper Naming (PR #616):** Synchronized all references to the `taipanstack_bootstrapper` script across documentation and the test suite to ensure consistent UX.

### 🧪 QA & Testing
* **Enhanced Test Suite:** Reached a total of **1,237 passing tests**, including new edge-case validation for bridge component fallbacks and resilience chaos scenarios.
* **[Fix] Bridge Coverage (PR #620):** Corrected missing test coverage for database and HTTP bridge fallback states, ensuring 100% reliability in failure recovery paths.

---

### Security Advice
We recommend upgrading to `v0.4.4` to ensure your pipelines are protected against the latest dependency vulnerabilities and to benefit from the hardened file system guards. 

Check your `pip-audit` reports to ensure the explicit ignores for `CVE-2026-3219` and `PYSEC-2022-42969` are correctly recognized as documented risks.
