# TaipanStack v0.4.4 Release Notes

**TaipanStack v0.4.4** is a massive consolidation release focusing on security hardening, extreme resilience testing, and 100% verified quality. This version integrates over **20 Pull Requests** addressing advanced security bypasses, chaos stability, and static typing excellence, culminating in a new milestone of **1,237 passing tests**.

See documentation at: [TaipanStack Dev Portal](../index.md).

---

## What's New & Fixed in v0.4.4

### 🛡️ Core Security & Sentinel Guards
* **[High] File Extension Hardening (PR #619):** Patched a critical bypass in `guard_file_extension` that allowed null bytes (`\x00`) and trailing periods/whitespace to mask malicious extensions.
* **[High] Symlink Loop Protection (PR #589):** Resolved an unhandled `RuntimeError` when the security guards encountered malicious circular symlink structures.
* **[Hardening] Retry Config Resilience (PR #618):** Enforced `math.isfinite` validation in the `RetryConfig` layer to prevent logic corruption or infinite loops caused by `NaN` configuration values.
* **[Hardening] Thread Safety (PR #578):** Mitigated potential thread exhaustion vectors in high-concurrency timeout decorators.
* **[Fuzzing] Automated Security Testing (PR #597, #605):** Leveraged Hypothesis to discover and fix a ReDoS vector in filename sanitization and performed extensive stress-testing on all security guards.
* **[Audit] Dependency Scanning & CVE Management:** 
    *   Addressed **CVE-2026-3219** (pip) via an explicit, documented ignore-vuln strategy.
    *   Addressed **PYSEC-2022-42969** (py) legacy vulnerability.
    *   Upgraded **pytest to 9.0.3** to remediate **CVE-2025-71176**.

### 🌀 Resilience & Chaos Engineering
* **[Resilience] Result Monad Integration (PR #592, #593):** Unified the Resilience layer with the core `Result` monad, ensuring that Circuit Breaker state changes and Retry attempts propagate structured errors natively.
* **[Chaos] State Transition Stability (PR #598):** Hardened the internal state machine of the Circuit Breaker to handle untracked error types without crashing the application.

### ⚡ Performance & CI/CD Optimization
* **[CI/CD] Infrastructure Hardening (PR #599, #610, #614):** Drastically streamlined the pipeline by removing redundant container tests and cleaning up IA-generated bypass scripts.
* **[Docs] Rendering & UX (PR #613):** Fixed Mermaid diagram syntax and MkDocs configuration to ensure a premium documentation experience.

### 🏗️ Refactoring & Clean Code
* **[Typing] Static Typing Excellence (PR #585, #601, #615):** Eliminated remaining `Any` usage and resolved MyPy strict mode violations across security models and core utilities.
* **[Clean Code] Structural Modernization (PR #591, #594, #606):** Reduced cyclomatic complexity across guards and filesystem utilities through strategic functional decomposition.
* **[Consistency] Version Synchronization (PR #586, #587, #596, #616):** Aligned version references and test count metrics across the bootstrapper, tests, and documentation.

### 🧪 QA & Testing
* **100% True Coverage (PR #579, #590, #611):** Achieved verified 100% line and branch coverage by resolving all `pragma: no cover` bypasses.
* **[Fix] Bridge Reliability (PR #620):** Added missing validation for database and HTTP bridge fallback states.
* **[Refactoring] Suite Standardization (PR #595, #600):** Standardized the entire test suite for environment isolation and concurrent execution compatibility.
