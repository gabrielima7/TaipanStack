# Release Notes — v0.7.0

**Release Date:** 2026-11-23

TaipanStack v0.7.0 introduces full automation for CI/CD delivery, continuous versioning with rollover rules, automated categorized GitHub Releases, PyPI publication with Sigstore Cosign signing, and GHCR container packaging.

---

## ✨ Features & Automation

- **Automated Delivery Pipeline**: Added unified GitHub Actions pipeline for publishing Python wheels and Docker images on `main` and version tags (`v*`).
- **Version Bump Rollover (.10)**: Automated semver bumping adhering to the `.10` rollover constraint (`x.y.10 -> x.(y+1).0`).
- **Release Categorization**: Automatically categorizes features, fixes, changes, and removals in GitHub releases.
- **Supply Chain Security**: Sigstore Cosign signing for wheels and CycloneDX SBOMs.
